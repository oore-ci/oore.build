Oore builds Flutter apps on your own Macs and delivers them to testers, Google
Play, and the App Store. Builds, signing keys, and artifacts stay on hardware
you operate. Pick the goal closest to yours.

<Callout title="Hosted UI">
  `ci.oore.build` is an optional browser client for an Oore backend that is
  already reachable over HTTPS. It does not host an Oore instance and is not
  part of the one-Mac Local Only path.
</Callout>
