---
title: '`oore version`'
status: implemented
description: 'Print the installed Oore release version.'
---

```text
oore version
```

The command prints the release version recorded in the install root's `VERSION` file.

Oore finds the install root in this order:

1. `OORE_INSTALL_ROOT`, when it is set.
2. The install root that holds the running `oore` binary. Oore follows symbolic links, so `/usr/local/bin/oore` linked to `~/.oore/bin/oore` reports `~/.oore`. The directory must contain `VERSION` or `install-manifest.json`.
3. `~/.oore`.

Without a `VERSION` file, the command prints the version the CLI was built from.
