Use these pages to look up an exact value, field, command, or API contract.
To get something done, start from [Get started](/start) or a
[how-to guide](/build) instead.

## Commands

- [`oore` command reference](/reference/cli) covers the operator CLI, from
  `oore install` to `oore pipeline migrate`.

## Configuration

- [`.oore.yaml` version 2](/reference/config/oore-yaml-v2) and
  [version 1](/reference/config/oore-yaml) define repository pipelines.
  [Move a pipeline into `.oore.yaml`](/build/pipelines/oore-yaml) says which
  one to use.
- [Pipeline settings](/reference/config/pipeline-settings) lists the trigger,
  schedule, timeout, approval, and size budget fields set on a pipeline.
- [Runner settings](/reference/config/runner) covers runner labels,
  dependency caches, VM images, and `oore.image.yaml`.
- [Daemon configuration](/reference/config/daemon) and
  [environment variables](/reference/config/environment) cover runtime
  settings.
- [Installer configuration](/reference/config/installer) covers release
  channels, install roles, and automation inputs.

## HTTP API

[HTTP API](/reference/api) is the entry point to the generated OpenAPI
reference. The generated category and operation pages list every path,
authentication rule, request body, and response.

## Product values

- [Error codes](/reference/errors) describes the API error envelope.
- [Build states](/reference/build-states) defines every build status and
  transition.
- [Setup states](/reference/setup-states) defines the setup status a backend
  returns.
- [Roles and permissions](/reference/roles) maps instance and project roles
  to what they can do.
- [Known limitations](/reference/known-limitations) lists the current
  platform, trust, browser, storage, and backup boundaries.
