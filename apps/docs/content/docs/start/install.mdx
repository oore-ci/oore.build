On this page you install the `oore` CLI and use it to install Oore's services
on this Mac. You pick the **Complete** role, which runs the control plane, the
web UI, and a build runner on one Mac.

## What you need

- A Mac that passed [Check that your Mac is ready](/start/prerequisites).
- Your macOS password, for the administrator prompt during setup.

## 1. Install the CLI

Run the script as your normal user. Do not prefix it with `sudo`:

```bash
curl -fsSL https://oore.build/install | bash
```

The script checks the signature of the stable release index and the checksum
of the CLI archive before it changes any file. It installs the CLI under
`~/.oore` and can add `~/.oore/bin` to your shell path. It installs no
services, Flutter, or web UI.

If the script changed your path, open a new terminal or run the `source`
command it printed.

## 2. Install the Complete role

```bash
oore install
```

Oore lists five roles and explains each one before it changes anything.
Choose **Complete**, the default. Oore downloads the release bundle and
installs the control plane, web UI, and runner.

An interactive install continues straight into `oore setup`, which is the next
page. Leave the terminal open.

## Check the result

In a second terminal, run:

```bash
oore version
```

The command prints the installed Oore version.

## Troubleshooting

**The script stops with a signature or checksum error**

The download did not match the signed release. Nothing was installed. Retry on
a network that does not rewrite HTTPS traffic, then
[report an issue](/operate/support/report-an-issue) if it still fails.

**`oore: command not found`**

Open a new terminal, or run the `source` command the script printed, so the
shell picks up `~/.oore/bin`.

**You are installing over SSH or from a script**

Pass the role explicitly with `oore install --profile complete`. Add `--plan`
to see the component plan without changes. A non-interactive install stops
after the components; run `oore setup` with a configuration file next, as
described in the [`oore setup` reference](/reference/cli/oore-setup).

**You want to install a different role**

The Runner, Control plane, Web node, and CLI only roles split Oore across
machines. See [Split Oore across Macs](/operate/deploy/split-roles) and the
[installer reference](/reference/config/installer).
