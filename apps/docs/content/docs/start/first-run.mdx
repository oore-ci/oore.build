On this page you finish setup: Oore starts its services, you create the owner
account in **Local Only**, and you confirm that the local runner is online.
Local Only signs you in without a password, but only from this Mac.

## What you need

- Oore installed with the Complete role, from [Install Oore](/start/install).
- A browser on this Mac.

## 1. Start setup

If `oore install` is still running in your terminal, it has already started
setup. Otherwise, run:

```bash
oore setup
```

On a local desktop session, Oore picks browser setup for the Complete role. It
shows the service plan, then asks for your macOS password to install the
services. The prompt expires after 60 seconds.

Over SSH, Oore picks terminal setup instead. The choices are the same, and
setup prints the SSH tunnel command to run on your own computer before you
sign in.

## 2. Choose Local Only

In the browser, under **How will you use Oore?**, choose
**Use Oore on this Mac**. This is Local Only: sign-in is passwordless and
works only over loopback.

You can turn on External Access later from **Settings**, without reinstalling.
Setup itself does not change the access choice after the owner exists.

## 3. Create the owner

Under **Owner account**, enter an account label such as `owner@local`. In
Local Only the label is only a name on this Mac. Oore does not send email or
ask for a password.

Setup then starts the control plane and web UI, creates the owner, and
enrolls the local runner.

## Check the result

The terminal ends with this line:

```text
Complete setup is ready.
```

Oore prints it only after it has verified every service. The browser opens
the Oore web UI on **Home**.

Then confirm two things:

1. Run `oore status` in a terminal. It reports the setup status as `ready`
   and the access as **this device**.
2. In the web UI, open **Settings > Runners**. One runner shows **Online**.

## Troubleshooting

**Setup stops before it changes anything**

The administrator prompt timed out or was declined. Run `oore setup` again.
Without an interactive terminal, Oore never prompts for a password; run
`sudo -v` first, then `oore setup`.

**The browser does not open**

Open the local web URL that setup printed. Over SSH, start the printed tunnel
command on your computer first and keep it open.

**You need team sign-in from day one**

Choose **Let people sign in with an identity provider** instead, and follow
[Configure External Access (OIDC)](/team/access/oidc). Read
[Which setup do I need?](/concepts/which-setup) if you are unsure. Every other
page in this path works the same with either choice.

**You want repeatable, scripted setup**

Put the answers in a YAML file and run `oore setup --config <file>`. See the
[`oore setup` reference](/reference/cli/oore-setup) for every field.
